# Pulse — Expense Tracker

Минималистичный трекер расходов на React + Vite.

## Запуск

```bash
npm install
npm run dev
```

## Страницы

- **Обзор** — баланс, доходы/расходы месяца, динамика за неделю, donut по категориям, последние операции
- **Операции** — поиск, фильтры по типу и категории, добавление и удаление
- **Аналитика** — периоды неделя/месяц/год, суммы, среднее в день, топ-категория, графики
- **Настройки** — тема (светлая/тёмная), шрифт (4 варианта), язык (RU/EN), валюта (₽/$/€), экспорт/импорт/сброс данных

## Стек

React 18, Vite, React Router 6, lucide-react, CSS-переменные, localStorage.
Без тяжёлых UI-библиотек — всё на чистых CSS-анимациях.
